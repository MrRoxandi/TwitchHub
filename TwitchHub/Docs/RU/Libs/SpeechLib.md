# SpeechLib

## Доступные функции

| Имя            | Аргументы      | Описание                                                                 |
| :------------- | :------------- | :----------------------------------------------------------------------- |
| `speak`        | `string text`  | Озвучивает `text`                                                        |
| `pause`        | -              | Ставит весь процесс озвучки на паузу                                     |
| `resume`       | -              | Возобновляет озвучивание                                                 |
| `clear`        | -              | Очищает очеред текстов на озвучивание                                    |
| `skip`         | -              | Пропускает текущее озвучиваемое сообщение                                |
| `setvolume`    | `int volume`   | Устанавливает громкость на значение `volume` в диапазоне `[0; 100]`      |
| `getvolume`    | -              | Получает текущий уровень громкости                                       |
| `setrate`      | `int rate`     | Установить скорость речи на значение на `volume` в диапазоне `[-10; 10]` |
| `getrate`      | -              | Получить текущую скорость речи                                           |
| `voices`       | -              | Получить `LuaTable` со всеми доступными голосами                         |
| `selectvoice`  | `string voice` | Установить доступный голос из списка доступных голосов                   |
| `reloadbwords` | -              | Перезагрузить конфигурацию запрещенных слов                              |

### Пример использования

Простой пример использования системы генерации голоса

```lua


function greet(uname)
  local message = utilslib:stringfmt("Привет, {name}", {uname})
  speechlib:speak(message)
end

greet("Roxandi")
```
